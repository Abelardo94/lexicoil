3 modos de examen

* Oficial
* \- Examenes predefinidos, como prueba real 
* \- Se pueden marcar las plabras par areparas
* \- Se tiene tiempo como un examen real
* 
* Práctica
* \- Se pueden consultar las palabras
* \- No tiene tiempo límite.
* 
* Personalizado
* \- 4 módulos que tiene el examen (lectura, escuchar, escribir, hablar)
* \- Se generan los exámenes, solo el de escribir y el de hablar, con el vocabulario seleccionado (la IA genera lógicamente con las palabras seleccionadas, discretizando la mejor opción).
* \- El modulo de leer y de escuchar no consume créditos directamente.
* 
* Los exámenes generados a traves de powershell pasan por un proceso de filtros en donde se evalúa la calidad de cada examen, si pasan la prueba se guarda localmente. Solamente esos exámenes son los que se cargan a la web.
* En la piscina de exámenes generados está el contenido para alimentar los modos oficial y práctica, pero también el personalizado se alimenta de esa piscina, como una base pero la IA genera también el contenido, de forma que sea contenido exclusivo para cada intento, es decir, que a un usuario no se le repita el mismo examen.
* 

Vocabulario

* Custom examns - redirije al examen personalizado
* Flash cards, repasa la palabra, traducción, lectura, escucha
* AI quiz: genera un cuestionario como un juego con las palabras seleccionadas (discretizar lógicamente).
* Listening game: Juego de escucha con las palabras seleccionadas (discretizar lógicamente)
* Phrases: Genera frases cortas con las palabras seleccionadas (discretizar lógicamente)
