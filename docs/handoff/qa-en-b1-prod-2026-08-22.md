que el script de npm no pasa.

## 2. Bug nuevo (#15): `Speaking — Teil 1 · undefined%`

**Dónde:** `js/ui/exam/results.js:505`. **Dos defectos en la misma línea.**

```js
html += `<div class="corr-mod"><h3>${isDE ? 'Sprechen' : 'Speaking'} — Teil ${sp.part.teil} · ${sp.score}%</h3><div class="corr-row ${passOk(sp.score) ? 'ok' : 'bad'}">…
```

### (a) `Teil` está a pelo — inglés y español

El nombre del módulo sí conmuta (`isDE ? 'Sprechen' : 'Speaking'`), pero **`Teil` no**. Todos sus
vecinos de ese bloque están bien: `Schreiben`/`Writing`, `Checkliste`/`Checklist`,
`Musterantwort`/`Model answer`, `Musterdialog`/`Model dialogue`. Es un olvido, y es exactamente la
misma familia que el 20ago-5. Segundo sitio con lo mismo: **`results.js:822`**.

Medido en prod, en/B1: 4 ocurrencias por examen — `Speaking — Teil 1..4`.

### (b) `undefined%`, y encima pinta rojo — **los dos idiomas, alemán live incluido**

`sp.score` **nunca existe** en el path orientativo:

```js
// js/bootstrap/featureSpeaking.js:28  buildOrientativeSpeakingHint()
return { note: …, words, min, lengthOk };   // ← no hay score
```

Y `speakingParts` se construye **solo** desde esa función (`results.js:276`). O sea que
`· ${sp.score}%` sale `undefined%` **siempre** que el Speaking no lo evalúe la IA, y
`passOk(undefined)` → `undefined >= 60` → `false` → la fila se pinta **`bad`**, en rojo,
como suspenso.

**El hermano de tres líneas más arriba ya lo resuelve:**

```js
// results.js:476 — el path de Writing, bien hecho
const rowCls = wp.score != null && !wp.orientative ? (passOk(wp.score) ? 'ok' : 'bad') : 'mid';
```

**Prueba en producción, en el mismo resultado de `de/B1` Exam 1** (alemán live, 19 exámenes):

```
Schreiben — Aufgabe 1        → .corr-row.mid   (neutra, correcto)
Schreiben — Aufgabe 2        → .corr-row.mid
Schreiben — Aufgabe 3        → .corr-row.mid
Sprechen — Teil 1 · undefined%  → .corr-row.bad   (roja)
Sprechen — Teil 2 · undefined%  → .corr-row.bad
Sprechen — Teil 3 · undefined%  → .corr-row.bad
```

Misma situación —"no evaluado"— y dos tratamientos distintos en la misma pantalla. El texto de la
fila ya dice `Nicht evaluiert (orientativ)` / `Not evaluated (orientative)`, así que el `%` no
debería estar ahí siquiera.

**Alcance:** el `undefined%` y el rojo son **agnósticos de idioma** → afectan a `de/B1` y `de/A2`
en producción, no solo al inglés. El `Teil` es solo inglés/español.

### Arreglo propuesto (una línea, calcado del vecino)

```js
const spScored = sp.score != null && !sp.orientative;
html += `<div class="corr-mod"><h3>${isDE ? 'Sprechen' : 'Speaking'} — ${isDE ? 'Teil' : 'Part'} ${sp.part.teil}${spScored ? ` · ${sp.score}%` : ''}</h3><div class="corr-row ${spScored ? (passOk(sp.score) ? 'ok' : 'bad') : 'mid'}">…
```

Más el `Teil` → `${isDE ? 'Teil' : 'Part'}` en `results.js:822`.

**No lo he tocado**: `results.js` es motor compartido y el (b) cambia lo que ve el alumno alemán en
producción. Decidid vosotros y lo hago.
